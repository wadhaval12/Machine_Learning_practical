# Machine Learning Algorithms Using Python

## Overview
This project demonstrates the implementation of different Machine Learning algorithms using Python and Scikit-learn. The experiments use a Diabetes Prediction Dataset to understand data preprocessing, model building, training, prediction, and evaluation.

## Algorithms Implemented

1. Linear Regression
2. Decision Tree
3. K-Means Clustering
4. K-Nearest Neighbors (KNN)
5. Random Forest
6. Support Vector Machine (SVM)
7. Naive Bayes
8. Perceptron

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
Diabetes Prediction Dataset containing patient-related features such as age, gender, BMI, hypertension, smoking history, HbA1c level, blood glucose level, and diabetes status.

## Learning Objectives
- Understand different Machine Learning algorithms.
- Perform data preprocessing and feature scaling.
- Train and test Machine Learning models.
- Evaluate model performance.
- Visualize results using graphs and confusion matrices.

## Project Status
Completed practical implementations for learning and educational purposes.
