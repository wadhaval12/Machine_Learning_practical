# Machine Learning Algorithms Using Python

## 1. Project Description
This project focuses on implementing eight different Machine Learning algorithms using Python and Scikit-learn. The project uses a Diabetes Prediction Dataset to understand data preprocessing, model training, prediction, and performance evaluation.

## 2. Algorithms Implemented
1. Linear Regression
2. Decision Tree
3. K-Means Clustering
4. K-Nearest Neighbors (KNN)
5. Random Forest
6. Support Vector Machine (SVM)
7. Naive Bayes
8. Perceptron

## 3. Dataset
**Dataset:** Diabetes Prediction Dataset

**Total Records:** 100,000

**Total Features:** 8 input features and 1 target variable.

Dataset attributes:
- Gender
- Age
- Hypertension
- Heart Disease
- Smoking History
- BMI
- HbA1c Level
- Blood Glucose Level
- Diabetes (Target Variable)
